# Method sheets

One sheet per module: the question the module answers, the procedure, the Excel functions the
course uses, the conditions to check, the classic mistakes, and how to report the result. Agents
read the sheet for the module before building anything. Students use them as the formula
reference for the whole course.

| Sheet | Module |
|---|---|
| `m1-probability.md` | Marginal, joint, conditional probability; independence; base rates |
| `m2-distributions.md` | Expected value, binomial, Poisson, normal, uniform |
| `m3-sampling-ci.md` | Sampling distributions, standard error, t and z intervals, sample size |
| `m4-one-sample-tests.md` | The seven steps, tails, t and z tests, errors, CI and test link |
| `m5-two-sample-tests.md` | Step zero (paired or independent), Welch t, paired t, interval for a difference |
| `m6-anova.md` | Family-wise error, the ANOVA table, F, conditions, Tukey HSD |
| `m7-chi-square.md` | Goodness of fit, independence, expected counts, combining categories |
| `rounding-policy.md` | The graded rounding rules |
| `manager-sentence.md` | What the one-line recommendation must contain, by module |
| `ai-guardrails.md` | The four AI rules and what an agent does when asked to break them |
