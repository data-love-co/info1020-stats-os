# Modules

One folder per module. Each holds the AI Block brief (what you build, what you give the tool, what
to verify against, which guardrail the block teaches) and the paste template for the So-What tab.

| Folder | Module | AI Block |
|---|---|---|
| `M1-Probability/` | Probability for business decisions | Base-rate explainer |
| `M2-Distributions/` | Probability distributions | Demand-planning simulator |
| `M3-Sampling-CI/` | Sampling and confidence intervals | CI calculator with an interpretation sentence |
| `M4-One-Sample/` | One-sample hypothesis testing | Seven-step test readout |
| `M5-Two-Sample/` | Two-sample hypothesis testing | A/B test readout |
| `M6-ANOVA/` | ANOVA | Group-comparison readout |
| `M7-Chi-Square/` | Chi-square | Segment-association audit |

The slide decks, workbooks, and notes guides live on Canvas, not here. This repo holds the AI side
of the course: the prompts, the skills, the data, and the method reference.
